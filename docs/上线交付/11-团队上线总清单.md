## 七、常见问题

| 问题 | 处理 |
| --- | --- |
| 网络连接失败 | 检查服务器地址带 /api |
| AI invalid api key 2049 | MiniMax 地址确认 api.minimaxi.com/v1 |
| 检测不到设备 | 检查 USB，重启桌面端 |
| 客户建档 400 | 姓名/手机号必填 |
| 403/404 | 权限不足或数据不属本店 |
| 数据误删 | 服务器每日 4 点自动备份可恢复 |
