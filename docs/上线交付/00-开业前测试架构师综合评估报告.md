## 二、架构评估

### 2.1 后端（NestJS + Prisma + SQLite）
- ✅ 30+ 主要接口稳定，5 级 RBAC 守卫
- ✅ 跨店数据隔离（scopedWhere interceptor）
- ✅ 关键写操作事务化
- ✅ DTO 校验 + API 版本化（/api 与 /api/v1）
- ✅ 设备 HMAC 鉴权（强随机密钥 + 签名心跳）
- ✅ 每日自动备份（保留 7 份）
- ✅ **v1.1 新增**：AI 解析健壮性（maxTokens 5000 + 健壮 parseJSON）
- ⚠️ SQLite 适合 <100 店；超过 100 店建议迁 PostgreSQL

### 2.2 前端（Electron + Vue 3 + Element Plus）
- ✅ 7 大分组可折叠菜单，视觉清爽
- ✅ keep-alive 保持操作状态
- ✅ 报告中心 4 级视图完整
- ✅ 居家调理 → 归档整体输出（前后端双重过滤）
- ✅ AI 结构化解读卡片式展示
- ✅ 报告删除权限 + 二次确认
- ✅ macOS 走 GitHub Actions 自动构建（x64 + arm64）
- ⚠️ 首次启动 macOS 未签名需"右键 Open"（内部分发可接受）

### 2.3 AI 体系
- ✅ 7 家供应商可切换（**无单点依赖**）
- ✅ MiniMax Code Plan 国内端点已跑通
- ✅ 结构化解读 10 字段（机器可消费）
- ✅ 付费流程闭环（门店提交 → 总部收款 → 生成）
- ✅ **v1.1 新增**：50 类循证证据库（PubMed/指南引用）
- ⚠️ MiniMax 推理慢（15-40s），需用户预期管理

### 2.4 设备层
- ✅ PB-66 加密狗定位澄清（**非传感器**）
- ✅ HMAC 鉴权 + 离线缓存
- ✅ 真实生物电检测硬件选型指南
- ⚠️ 多台 PB-66 撞号（需 Rockey 私有协议 SDK，**单店无影响**）
