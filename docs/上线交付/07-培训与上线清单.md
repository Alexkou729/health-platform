## 六、常见问题速查

| 问题 | 处理 |
| --- | --- |
| AI invalid api key 2049 | MiniMax 国内 Key 确认地址 `api.minimaxi.com/v1` |
| 检测不到设备 | 检查 USB，桌面端重启 |
| 客户建档 400 | 姓名/手机号必填 |
| 403/404 | 权限不足或数据不属本店 |
| 数据误删 | 服务器每日 4 点自动备份 |
| 登录失败 | 检查服务器地址带 `/api`、账号密码正确 |
