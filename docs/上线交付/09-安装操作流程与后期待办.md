## 一、桌面端安装（Windows）

### 1. 下载
- 群文件：`健康管理系统-1.0.0-x64.exe`（88MB）
- macOS：GitHub Actions → Artifacts → 下载 .zip

### 2. 安装
- 双击 → 选安装路径 → 下一步 → 完成
- 桌面生成"健康管理系统"快捷方式

### 3. 首次登录
- 启动 → 填服务器地址：`http://47.99.147.106:3015/api`
- 账号：`admin` / `admin123`
- 立即改密码（系统设置 → 修改密码）

## 二、macOS 安装

1. 下载 .zip → 双击解压
2. 把 `健康管理系统.app` 拖入"应用程序"文件夹
3. **首次启动**：右键 `健康管理系统` → "打开" → "打开"（绕过未签名验证）
4. 后续可正常双击

## 三、服务器端准备（一次性 · 总部负责）

```bash
# 1. 上传代码
scp -r platform/ root@47.99.147.106:/opt/health-platform/

# 2. 安装依赖
cd /opt/health-platform/apps/backend
npm install --legacy-peer-deps

# 3. 装 Chromium（PDF 必需）
mkdir -p /opt/chromium && cd /opt/chromium
curl -fsSL -o chrome.zip https://cdn.npmmirror.com/binaries/chrome-for-testing/120.0.6099.109/linux64/chrome-linux64.zip
unzip -o chrome.zip
dnf install -y atk cups-libs nss mesa-libgbm libXcomposite libXdamage

# 4. 配 .env
cat >> /opt/health-platform/.env <<EOF
CHROMIUM_PATH=/opt/chromium/chrome-linux64/chrome
EOF

# 5. 启动
cd /opt/health-platform
pm2 start apps/backend/dist/main.js --name health-backend
pm2 save

# 6. 验证
curl http://127.0.0.1:3015/health
```

详见 `aliyun-deploy.md`。
