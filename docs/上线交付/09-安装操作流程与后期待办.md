# 安装操作流程与后期待办清单

> 版本 v1.0 ｜ 用途：安装部署 + 后期运营待办总览

## 一、安装文件操作流程

### 1. Windows 桌面端（门店电脑用）

本地安装包（可直接用）：
```
E:\work Codex\健康管理\platform\LOCAL-INSTALL\健康管理系统-1.0.0-x64.exe
```

安装步骤：
1. 双击 .exe 按提示安装
2. 桌面打开「健康管理系统」
3. 登录页「服务器地址」填 http://47.99.147.106:3015/api
4. 账号 admin / 密码 admin123 登录

### 2. Windows + macOS 安装包（从 GitHub CI 下载）

1. 打开 https://github.com/Alexkou729/health-platform/actions
2. 点进最新的 Build Desktop 运行记录
3. 等两个任务变绿（Windows 桌面端 + macOS 桌面端）
4. 页面最下方 Artifacts 下载：
   - windows-desktop：解压得到 Windows .exe
   - macos-desktop：解压得到 macOS .dmg / .zip

### 3. 移动端 H5（Mac/手机客户临时用）

浏览器直接打开：http://47.99.147.106:3015/

### 4. 微信小程序（后期，需 AppID）

源码在：E:\work Codex\健康管理\platform\apps\mobile-app\dist\（需先填 AppID 重新构建）

## 三、后续代码更新方式

已在阿里云服务器配好 GitHub SSH 通道，后续改功能由开发方从服务器直接推送更新，GitHub Actions 自动重新打包 Windows + macOS，运营方只需去 Actions 页下载新安装包。
