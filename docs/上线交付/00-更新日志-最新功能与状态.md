## 1. AI 智能化（本次重点）

### 1.1 结构化 AI 解读（新）
- **端点**：`POST /api/ai/interpret/:reportId/structured`（仅总部可调）
- **返回 JSON**（10 字段，固定 schema）：
  ```json
  {
    "overallAssessment": "整体评估(150-200字)",
    "constitutionAnalysis": "中医体质解读(200-300字)",
    "keyFindings": ["关键发现1", "关键发现2", ...],
    "risks": [{"indicator":"...","level":"高|中|低","advice":"..."}],
    "diet": [{"item":"食物","type":"宜|忌","reason":"原因"}],
    "exercise": [{"type":"...","intensity":"...","frequency":"...","duration":"..."}],
    "lifestyle": ["..."],
    "meridians": [{"name":"穴位","method":"按摩方法"}],
    "therapies": [{"name":"项目","frequency":"频次"}],
    "followUp": {"days":30,"watchIndicators":["..."]}
  }
  ```
- **前端展示**：卡片式结构化（整体评估 / 体质解读 / 关键发现 / 风险关注带分级标签 / 饮食宜忌 / 运动 / 作息 / 经络穴位 / 理疗 / 复检建议）
- **健壮解析**：`parseJSON` 用**括号配平**算法处理 MiniMax-M3 推理模型返回的 `<think>...JSON...</think>` 格式（剥离思考、找最大平衡对象）
- **性能调优**：`maxTokens` 2200→**5000**（防止结构化 JSON 截断）；axios 超时 30s→**120s**（覆盖 15-40s 推理耗时）

```
门店提交工单（AI 解读 ¥9.9）
```

## 2. 报告权威性

### 2.1 大数据循证证据库（新）
- 文件：`apps/backend/src/modules/report/report-evidence.data.ts`
- **50 个检测类别**全部接入循证依据：
  - `scientificBasis`：科学原理（如 Framingham 风险模型 / 中国血脂管理指南 / BIA 身体成分 / Ryodoraku 经络电测量）
  - `reference` + `referenceUrl`：参考文献（PubMed / 权威指南链接，可溯源）
  - `riskFactors`：循证风险因素列表
  - `genderNote`：性别重点（女性 18 类、男性 12 类专属）
- **报告详情新增「评估依据」标签页**：显示科学依据 + 参考文献溯源链接 + 风险因素标签云 + 性别重点

### 2.2 居家调理 → 归档整体输出（新）
- 之前的 bug：综合报告（comprehensive）中 28 条「居家调理」建议被当作数值指标（出现假数值、风险评估）
- **修复**：
  - 后端 `generateIndicators` 跳过 `name === '居家调理'` 条目 → 不生成数值/状态
  - 后端收集为 `suggestions.homeCareAdvice` 数组
  - 前端「检测明细」表格自动过滤居家调理/分类头（`indicatorRows` 过滤）
  - PDF 渲染同步过滤
  - 报告页底部渲染为「📋 归档：综合居家调理建议」整体块（一段连贯文字，"仅文字建议，无数值与风险评估"）
  - 无内容时该块不显示（`v-if` 空着）

## 4. PDF 导出修复

### 4.1 服务器装 Chromium
- **根因**：服务器只装了 `puppeteer-core`（无浏览器），系统也无 Chromium → PDF 端点返回 503
- **修复**：
  - 从 npmmirror 国内镜像下载 Chrome for Testing 120 → `/opt/chromium/chrome-linux64/chrome`
  - `dnf install atk cups-libs libdrm mesa-libgbm nss ...` 补齐依赖
  - `CHROMIUM_PATH=/opt/chromium/chrome-linux64/chrome` 写入 `.env`
- **验证**：`GET /api/reports/:id/pdf` → 200 + `Content-Type: application/pdf` + `%PDF-1.4`（~85KB）

## 5. 设备定位（重要澄清）

### 5.1 PB-66 = Rockey 加密狗
- VID 0x5608 / PID 0x080D（飞天诚信 Rockey 系列）
- USB SerialNumberString 是固定占位符 `ROCKEY `，**所有同型号狗完全一样**
- **不是生理传感器**，不测生物电/手掌阻抗
- 系统中的角色：授权/防伪/操作触发（License Dongle）

### 5.2 原"量子共振 522 项"是营销话术
- 315 消费者权益日已曝光：用公猫测出"卵巢护理"建议
- 学术上"量子弱磁场共振"是伪科学（Quackwatch 打假）

### 5.3 真实生物电检测需采购开源硬件
推荐：
| 设备 | 价格 | 接口 |
|---|---|---|
| **BITalino (r)evolution** | €149-250 | BLE/USB，真·EDA+ECG |
| **Seeed Grove GSR** | $15-25 + Arduino | 串口，真·皮肤电导 |
| **HealthyPi 5** | $199-250 | WiFi/BLE，真·ECG+PPG+SpO2 |
| **ADI AD5940BIOZ** | $500-720 | 真·生物阻抗 AFE |

详细接入方案见 `docs/设备代工/生物电设备采购清单与接入方案.md`
