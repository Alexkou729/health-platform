## 一、快速开始

### 1. 安装桌面端
双击安装包 `健康管理系统-1.0.0-x64.exe`，按提示安装，从桌面启动。
- **macOS 同事**：从 GitHub Actions Artifacts 下载 .zip，解压后拖入"应用程序"，**首次启动右键 → 打开**（绕过未签名验证）

### 2. 配置服务器地址
登录页「服务器地址」：
```
http://47.99.147.106:3015/api
```

### 3. 默认账号

| 角色 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 总部超级管理员 | admin | admin123 | 全权限 |
| 门店店长 | 总部审批后分配 | 分配 | 仅本店 + 部分功能 |

> ⚠️ 首次登录立即修改默认密码（系统设置 → 修改密码）

## 四、报告中心（重点）

### 1. 报告三级视图（v1.1 优化）
- **客户列表**（搜姓名/手机）→ **本次检测时间**（按日）→ **本次检测报告分类** → **报告详情**

### 2. 报告详情 6 大标签页
1. **检测明细**（四列表：项目/正常范围/实测值/结果，红绿分色）
2. **评估结论**
3. **评估依据**（v1.1 新增）— 科学依据 + 参考文献溯源 + 风险因素 + 性别重点
4. **中医体质 / 药食同源 / 调理方案**
5. **AI 解读**（v1.1 新增结构化卡片）— 整体评估/体质解读/风险关注/饮食/运动/作息/经络穴位/理疗/复检
6. **重点关注**

### 3. 居家调理 → 归档（v1.1 重要变化）
- **检测明细不再显示**居家调理的假数值和风险评估
- 报告末尾的「📋 归档：综合居家调理建议」块只显示文字建议
- 无内容时该块不显示

### 4. 删除报告（v1.1 权限收紧）
- **仅店铺超级管理员（STORE_ADMIN）和总部超级管理员（SUPER_ADMIN）**可见删除按钮
- 点击后弹二次确认（确认在右，"删除"红色/取消灰色）
- 防误关：点遮罩不会关闭

### 5. 返回上一级
- 报告详情「返回」回到「本次检测的全部报告列表」（不再跳级）

## 六、设备管理（v1.1 重要澄清）

### PB-66 是什么？
- 飞天诚信 **Rockey 加密狗**（VID 0x5608 / PID 0x080D）
- **不是生理传感器**，不测生物电
- 在系统中的作用：**授权/防伪/操作触发**

### 真实生物电检测
- 需采购开源硬件（见 `设备代工/生物电设备采购清单与接入方案.md`）
- 推荐：BITalino (€149-250)、Grove GSR + Arduino (¥150)、HealthyPi 5 ($199)
- 设备到货后由开发团队接入

## 八、常见问题（v1.1）

| 问题 | 处理 |
|---|---|
| 网络失败 | 检查 API 地址带 http:// 和 /api |
| Unauthorized | 重新登录 |
| AI 解读 `R.interpretStructured is not a function` | **升级到 v1.1 桌面端** |
| AI 解读 `invalid api key` | MiniMax 国内 Key 走 `api.minimaxi.com/v1` |
| 报告只有 `{raw:"..."}` | **点"重新生成"**（v1.1 maxTokens 5000 + 健壮解析） |
| PDF 503 | 通知技术：服务器需装 Chromium + CHROMIUM_PATH |
| 设备连接失败 | PB-66 只做授权，需另采真实检测设备 |

## 九、断网/弱网应急

| 场景 | 表现 | 应急 |
|---|---|---|
| 后端不可达 | "网络连接失败" | 自动降级"离线演示模式" |
| Wi-Fi 中断 | 检测中数据丢失 | 重连后人工补录 |
| API 超时 | "请求超时" | 重试；连续 3 次失败联系技术 |
| 数据库故障 | 全部 500 | 总部启动应急切换到备用 RDS |

## 十、错误码速查

| 码 | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | — |
| 400 | 参数错误 | 检查必填/字段类型 |
| 401 | 未登录 | 重新登录 |
| 403 | 权限不足 | 联系总部开通 |
| 404 | 不存在/越门店 | 确认归属 |
| 500 | 系统异常 | 看日志/联系技术 |
| 503 | 服务未配置 | 检查系统设置 → AI/支付/CHROMIUM_PATH |
