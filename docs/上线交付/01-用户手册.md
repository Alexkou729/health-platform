# 健康管理系统 · 用户操作手册

> 版本：v1.0.0 ｜ 适用对象：总部运营人员、门店店长、健康顾问/医师、前台
> 系统为「总部 + 加盟门店」两级 SaaS 平台，桌面端 + 云端实时联动。

---

## 一、快速开始

### 1. 安装桌面端
双击安装包 `健康管理系统-1.0.0-x64.exe`，按提示安装，从桌面启动「健康管理系统」。

### 2. 配置服务器地址（首次登录）
登录页「服务器地址」填写：
```
http://47.99.147.106:3015/api
```
点「配置」即时生效。

### 3. 登录
| 角色 | 账号 | 默认密码 | 说明 |
|------|------|----------|------|
| 总部超级管理员 | admin | admin123 | 全权限，看全部门店数据 |
| 门店店长 | （总部审批开通后分配） | （分配） | 仅本店数据 |

> ⚠️ 首次登录后请在「系统设置 → 修改密码」立即修改默认密码（当前版本可联系总部管理员重置）。

## 二、服务器配置三个字段怎么填

打开「系统设置」，有三个服务器相关字段：

| 字段 | 怎么填 | 说明 |
|------|--------|------|
| **API 地址** | `http://47.99.147.106:3015/api` | 后端接口地址，**必填且必须带 `/api`** |
| **设备网关** | 保持默认 `ws://localhost:8888/ws` | 这是门店电脑本机的设备网关地址，**不要改成服务器**。检测仪是 USB 设备，插在门店电脑上，由桌面端本地驱动读取数据后上传云端 |
| **H5 域名** | `http://47.99.147.106:3015`（有域名后改 `https://你的域名`） | 客户在手机上看报告的公开页面域名，用于生成分享链接 |

> 说明：设备网关当前为「本机设备网关」；检测仪通过门店电脑的 USB 口连接，桌面端自动检测设备并启动网关，无需在服务器配置里额外修改。

## 三、门店日常操作流程（核心闭环）

### 第 1 步：录入客户
「客户管理 → 新建客户」，填姓名、手机号、性别、出生日期、身高体重等。

### 第 2 步：做体质检测
「检测中心」选择客户 → 连接检测仪 → 开始 60 秒检测 → 系统自动生成报告。

### 第 3 步：查看/发送报告
「报告中心」查看检测报告，点「发送」生成**免登录分享链接**，复制发给客户，客户手机扫码/点开即可看报告。

### 第 4 步：历史对比
「历史对比」选择客户，对比多次检测的指标变化趋势。

### 第 5 步：制定调理方案
「调理方案 → 新建方案」，选择客户、填写中医辨证、添加调理项目（已内置艾灸/拔罐/推拿/足浴等 12 项理调项目库）。

### 第 6 步：预约管理
「预约管理」查看/确认/开始/完成/取消预约，管理客户到店服务。

### 第 7 步：向总部申请专业服务
「服务申请 → 发起申请」：
- **AI 报告解读** ¥9.9/次
- **调理方案** ¥99/次
- **远程会诊** ¥99/次

总部受理后，结果会回到「服务申请」列表。

### 第 8 步：下单收款
「订单管理」管理套餐销售与订单；总部完成的专业服务会在门店自动生成订单。

## 四、总部运营操作

### 1. 加盟申请审批
「加盟管理 → 加盟申请」：查看商家自助提交的加盟申请 → 「通过开通」自动生成门店 + 商家账号（弹窗显示账号密码）→ 安全转交商家。

### 2. 服务工单处理
「加盟管理 → 服务工单」：受理 / 完成 / 驳回门店提交的专业服务。完成时自动生成账单并登记 AI 消费。

### 3. 门店订阅管理
「加盟管理 → 订阅管理」：为门店开通订阅套餐（FREE/BASIC/PRO/FLAGSHIP），设置 AI 配额与价格。

### 4. 账单与收款
「加盟管理 → 账单/AI消费」：查看各门店账单，点「登记收款」记录已收款。

### 5. AI 接口配置（总部专属）
「系统设置 → AI 接口配置」或「加盟管理 → AI接口配置」：
选择模型供应商（通义千问/豆包/Kimi/MiniMax/DeepSeek/智谱/蚂蚁百灵），系统自动填充接口地址和模型名，粘贴 API Key，点「保存并生效」「测试连接」。

### 6. 门店与员工管理
- 「门店管理」：新增/编辑门店。
- 「员工管理」：新增员工、设置角色、点「权限」勾选该员工可用功能。

## 五、权限体系（总部 / 门店 两级）

| 功能 | 总部 admin | 门店店长 | 普通店员 |
|------|:---:|:---:|:---:|
| 检测中心 / 客户 / 报告 / 订单 / 预约 / 调理方案 | ✅ | ✅ | 按勾选 |
| 服务申请（向总部） | — | ✅ | 按勾选 |
| 员工管理（本店） | ✅ | ✅ | ❌ |
| 门店管理 / 加盟管理 / AI接口配置 | ✅ | ❌ | ❌ |
| 运营报表 / 收入 | ✅ | ✅（本店） | ❌ |

> 门店账号只能看到自己门店的数据，访问总部接口会被拒绝（403）。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 提示「网络连接失败」 | 检查服务器地址是否带 `http://` 和 `/api` |
| 提示「Unauthorized」 | 重新登录 |
| AI 测试失败 invalid api key (2049) | MiniMax 国内 Key 请确认接口地址为 `https://api.minimaxi.com/v1` |
| 检测不到设备 | 确认检测仪 USB 已插好，桌面端已启动设备网关 |

## 七、数据安全与备份
服务器每日凌晨 4 点自动备份数据库，保留最近 7 份，可在服务器 `/opt/health-platform/backups/` 目录找回历史数据。
