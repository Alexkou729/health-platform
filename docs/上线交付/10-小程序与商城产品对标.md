## 三、竞品对标

| 竞品 | 他们的做法 | 我们的差异 |
|---|---|---|
| **美团医美/中医** | 单店入驻，**平台抽 20-30%** | 加盟商独立 SaaS，**总部代生成 AI** |
| **平安好医生** | 在线问诊 + AI 辅助 | **到店体验 + 真实检测** + 报告 |
| **微医** | 挂号 + 复诊 | **养生/医美/美容院场景** |
| **中医世家 SaaS** | 单店软件 | **循证依据 + 总部代 AI** |

### 核心优势
1. **50 类循证依据** — 同行话术"调理"，我们给文献链接
2. **总部代生成 AI** — 加盟商不需懂技术、不需 API Key
3. **门店数据隔离** — 同行混在一起，我们每家店独立
4. **真实生物电检测**（待接入） — 同行多用"量子共振"伪科学
