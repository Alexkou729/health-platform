# 小程序 + 电子商城 + 上门服务 · 产品对标与定位

> 版本 v1.0 ｜ 目的：明确小程序客户端定位，对标同类平台，指导后续迭代

## 一、小程序定位（客户端 C 端）

小程序面向**客户**（不是店员），核心能力：

| 模块 | 客户价值 |
| --- | --- |
| 手机号登录 | 电话登录，自动绑定后台客户档案，数据全程打通 |
| 查报告 | 微信登录后直接看自己的 40+ 份检测报告 + AI 解读 |
| 调理方案 | 看自己的调理方案、项目、进度 |
| 健康商城 | 保健品/调理包/保健用品，门店审核上架，门店销售返提成 |
| 上门服务 | 上门理疗/上门检测，总台排单、门店接单、服务、结算 |
| 优惠券/会员 | 领券、用券、会员等级 |
| 预约 | 到店预约 |

## 二、对标平台

| 维度 | 京东健康/阿里健康 | 美团/点评 | 有赞/微盟商城 | 本平台 |
| --- | --- | --- | --- | --- |
| 健康检测 | 线上问诊 | 无 | 无 | 线下 60 秒检测 + 报告 |
| 商城 | 自营 B2C | 团购 | SaaS 商城 | 总部+门店联合商城 |
| 上门服务 | 少 | 到店团购 | 无 | 上门理疗/检测 |
| 客户管理 | 弱 | 无 | 有 | 检测+客户+订单一体化 |
| 加盟赋能 | 无 | 平台抽佣高 | 软件服务 | 总部系统+AI+供应链赋能 |
| 门店提成 | 无 | 抽佣 | 无 | 门店销售商品返提成 |
| 结算 | 自营 | 平台 | 商家 | 总部设置结算比例，自动结算 |

对标结论：本平台不是单一商城或问诊，而是「健康检测 + 商城 + 上门服务 + 加盟连锁」的一体化门店经营与客户服务生态，差异化明显。

## 三、订单流转与结算机制

1. 客户在小程序下单（商城/上门服务）。
2. 订单归属门店（商城按商品归属门店；上门服务总台排单）。
3. 总台排单（上门服务）→ 门店接单 → 服务执行 → 完成。
4. 总台收款 → 服务完成给门店结算（按总台设置的结算比例）。
5. 商城商品销售 → 门店按商品提成比例返佣。
