# 健康管理系统 · 开业操作 SOP（标准作业程序）

> 版本 v1.0 ｜ 适用：总部运营、门店店长、健康顾问/医师、前台
> 目标：从「装好系统」到「开门营业」每一步可照着做

## 二、日常营业操作流程（门店端）

### 第 1 步：录入/查找客户
「客户管理 → 增加客户」：填姓名、手机号、性别、出生日期、身高体重。

### 第 2 步：做 60 秒体质检测
「检测中心」：选客户 → 确认设备已连接 → 开始检测 → 等待 60 秒 → 自动生成 40+ 份报告。

### 第 3 步：查看并发送报告
「报告中心」：打开报告查看评分/指标/结论 → 点「发送」生成免登录分享链接 → 复制发给客户。

### 第 4 步：历史对比（复购话术）
「历史对比」：选客户对比多次检测，讲「上个月 vs 这个月」的变化，引导复购。

### 第 5 步：制定调理方案
「调理方案 → 新建方案」：选客户 → 填中医辨证 → 选理调项目（艾灸/推拿/足浴等）→ 生成方案与价格。

### 第 6 步：预约到店
「预约管理」：查看今日预约 → 客户到店点「开始」→ 服务完点「完成」。

### 第 7 步：下单收款
「订单管理 → 创建订单」：选客户 → 选套餐/服务 → 可输优惠券码 → 确认金额 → 收款。

### 第 8 步：向总部申请专业服务（进阶）
「服务申请 → 发起申请」：AI 报告解读 ¥9.9 / 调理方案 ¥99 / 远程会诊 ¥99 → 总部受理后结果回到列表。

## 三、总部运营操作

### 1. 加盟审批
「加盟管理 → 加盟申请」：查看申请 → 「通过开通」自动生成门店+账号（弹窗显示账号密码，安全转交）。

### 2. 服务工单
「加盟管理 → 服务工单」：受理 → 完成（自动出结果 + 生成账单 + 门店订单）。

### 3. 订阅与收费
「加盟管理 → 订阅管理」：给门店开通订阅套餐、AI 配额。
「加盟管理 → 账单/AI消费」：登记收款。

### 4. 门店与员工
「门店管理」：增加/编辑门店（地址、营业执照等）。
「员工管理」：新增员工、设角色、点「权限」勾选功能。

### 5. AI 接口配置（总部专属）
「系统设置 → AI 接口配置」：选模型（MiniMax/千问/豆包/Kimi/DeepSeek/智谱/蚂蚁百灵）→ 自动填地址模型 → 贴 API Key → 测试连接。

## 五、优惠券营销

1. 「营销中心 → 创建优惠券」：满减券/折扣券，设面值、门槛、总量、有效期。
2. 给客户「发券」。
3. 下单时输入券码自动抵扣，重复用券会被拦截。

## 六、小程序真机预览（AppID 配置）

### 第一步：注册小程序（一次性）
1. 打开 `https://mp.weixin.qq.com` 注册「小程序」账号（需企业/个体户营业执照）。
2. 登录后进入「开发 → 开发管理 → 开发设置」，复制 **AppID(小程序ID)**。

### 第二步：填入 AppID
1. 打开文件：`platform/apps/mobile-app/src/manifest.json`
2. 找到 `"mp-weixin": { "appid": "" }`，把空串改成你的 AppID：
   ```
   "mp-weixin": { "appid": "wx1234567890abcdef", ... }
   ```

### 第三步：重新构建小程序
在 `platform/apps/mobile-app` 目录执行 `npm run build:mp-weixin`，构建产物在 `dist/`。

### 第四步：真机预览
1. 下载「微信开发者工具」，用小程序管理员微信扫码登录。
2. 「导入项目」选择 `platform/apps/mobile-app/dist` 目录。
3. 工具自动识别 AppID，点「预览」生成二维码。
4. 手机微信扫码即可真机预览（管理员或体验成员）。

## 七、常见问题

| 问题 | 处理 |
| --- | --- |
| AI 测试失败 invalid api key (2049) | MiniMax 国内 Key 确认地址是 `https://api.minimaxi.com/v1` |
| 检测不到设备 | 确认检测仪 USB 插好，桌面端已启动 |
| 客户建档 400 | 检查必填「姓名」「手机号」是否填写 |
| 越权提示 403/404 | 账号权限不足或数据不属于本店，联系总部 |
| 数据被误删 | 服务器每日 4 点自动备份，可从 `/opt/health-platform/backups/` 恢复 |

## 八、每日收工清单

1. 核对今日订单与收款是否一致。
2. 未完成预约安排次日跟进。
3. 关闭桌面端（数据已实时存云端，无需手工备份）。
4. 新客户当天完成建档，不隔夜。
