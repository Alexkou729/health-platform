## 二、系统能力清单（v1.1）

| 模块 | 能力 |
|---|---|
| 检测 | 60 秒手掌检测，自动生成 40+ 份报告（真实数据管线 + 演示角标 isDemo） |
| 报告 | 评分/指标/结论/建议 + **循证依据** + **AI 结构化解读** + PDF + 分享链接 + 历史对比 + 居家调理归档 |
| 客户 | 建档、标签、等级、检测历史、门店数据隔离 |
| 订单 | 套餐销售、优惠券核销、支付/退款/取消状态机 |
| 调理方案 | 中医辨证 + 12 项理调项目库 + 医嘱建议 |
| 预约 | 确认/开始/完成/取消 |
| 营销 | 优惠券创建/发券/下单核销 |
| 加盟 | 商家自助申请，总部审批，自动开户，订阅计费，账单，结算比例 |
| 权限 | 总部/店长/医师/顾问/前台 5 级 + 细粒度勾选 |
| AI | **7 家**大模型可切换 · **结构化 JSON 解读** · **付费流程**（门店提交 9.9 → 总部收款后生成） |
| 设备 | USB 检测仪 + 网络设备独立签名鉴权（**PB-66 = Rockey 加密狗定位澄清**） |

### 2.1 v1.1 新增能力

| 能力 | 端点/位置 |
|---|---|
| AI 结构化解读 | `POST /api/ai/interpret/:reportId/structured`（仅总部） |
| 报告循证依据 | `GET /api/reports/:id` → `suggestions.evidence` |
| 居家调理归档 | `GET /api/reports/:id` → `suggestions.homeCareAdvice` |
| PDF 报告导出 | `GET /api/reports/:id/pdf`（需服务器装 Chromium） |
| 报告删除 | `DELETE /api/reports/:id`（仅 SUPER_ADMIN/STORE_ADMIN） |
