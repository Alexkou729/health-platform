# 商业模式与加盟方案

> 版本：v1.0 ｜ 定位：大健康 SaaS + 加盟连锁平台

## 一、一句话商业模式

以智能中医体质检测为流量入口，以 SaaS 系统 + AI 专业服务为利润引擎，以加盟连锁快速复制门店。

核心逻辑：总部把「检测设备 + 管理系统 + AI 专业能力」打包赋能给养生馆、医馆、美容院等门店；门店负责获客与本地服务，总部负责平台、AI、供应链与标准化，双方按服务分润。

## 二、盈利模式（总部收入结构）

| 收入项 | 模式 | 定价参考 |
| --- | --- | --- |
| 设备销售 | 一次性销售 Quantum Analyzer 手掌检测仪 | 建议 ¥3,980–¥9,800/台 |
| 软件订阅 | 门店年费订阅 SaaS 系统 | 免费版 / 基础版 / 专业版 / 旗舰版，建议 ¥2,999–¥19,999/年 |
| AI 专业服务费 | 门店向总部付费申请 AI 服务，总部分润 | AI 报告解读 ¥9.9/次、调理方案 ¥99/次、远程会诊 ¥99/次 |
| 供应链/耗材 | 理调项目耗材、养生品集采 | 艾灸条、足浴包、药膳包等 |
| 加盟费/保证金 | 加盟品牌授权 | 按城市分级，建议 ¥1万–¥10万 |

利润结构亮点：AI 服务为边际成本趋近于零的复购型收入，门店用得越多，总部赚得越多。

## 三、门店为什么愿意加盟（价值主张）

1. 低成本获客：60 秒无创检测，生成 40 份报告 + AI 解读，体验感强，容易留客。
2. 专业能力补强：门店无需懂中医，总部 AI 出具调理方案和医嘱建议，降低对医师的依赖。
3. 远程会诊：遇到复杂客户，一键申请总部医师远程会诊，提升成交与客单价。
4. 数字化管理：客户档案、预约、订单、报表、员工权限一体化，告别手工记账。
5. 数据安全：门店数据独立存储、严格隔离，客户隐私有保障，对加盟商是卖点。

## 四、加盟体系设计（两级 SaaS）

### 1. 角色与权限

| 角色 | 权限 |
| --- | --- |
| 总部 admin | 全权限：加盟审批、门店管理、服务工单、订阅计费、AI 配置、全部门店报表 |
| 门店店长 | 本店经营：检测、客户、报告、订单、预约、调理方案、服务申请 |
| 门店店员 | 按店长勾选的功能权限，可细粒度控制 |

### 2. 加盟流程

1. 商家在系统登录页「申请加盟入驻」提交信息（免登录）。
2. 总部在「加盟管理 → 加盟申请」审批，一键开通门店 + 商家账号。
3. 商家安装桌面端，登录即用（已内置 12 项理调库 + 4 个标准套餐）。

### 3. 服务工单（门店 → 总部）

门店提交付费服务申请 → 总部受理 → 完成时自动出结果 + 生成账单 + 门店订单 → 总部登记收款。

## 六、试点与扩张节奏

| 阶段 | 动作 | 目标 |
| --- | --- | --- |
| 第 0–1 个月 | 1 家自营店试点，跑通闭环，打磨话术与套餐 | 验证单店模型 |
| 第 2–3 个月 | 开放 3–5 家加盟，验证服务工单与分润 | 跑通加盟模型 |
| 第 4–6 个月 | 区域招商，标准化培训与供应链 | 形成区域网络 |
| 第 7–12 个月 | 多区域复制，数据看板驱动经营 | 规模盈利 |
