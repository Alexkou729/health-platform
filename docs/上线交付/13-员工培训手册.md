## 第一天：理论 + 演示

### 上午 9:00-12:00 · 系统架构与能力
1. **v1.1 新能力总览**（30 min）
   - AI 结构化解读、循证证据库、PDF 导出、7 大分组、keep-alive
2. **角色权限矩阵**（30 min）
   - SUPER_ADMIN / STORE_ADMIN / DOCTOR / CONSULTANT / RECEPTIONIST
   - 细粒度勾选（员工管理 → 权限）
   - **报告删除仅 SUPER_ADMIN/STORE_ADMIN**（v1.1 强调）
3. **数据流：检测 → 报告 → AI 解读**（30 min）
   - 客户端发起 → 服务端落库 → 报告引擎生成 40+ 类 → AI 结构化解读
4. **设备澄清**（15 min）
   - PB-66 = Rockey 加密狗（不是传感器）
   - 真实检测需另采硬件
5. **7 大分组菜单演示**（45 min）
   - 工作台 / 客户中心 / 服务交付 / 商品订单 / 加盟运营 / 数据设备 / 系统设置
   - keep-alive 现场演示（切走再回来保留状态）

### 下午 14:00-17:00 · 关键流程实操

#### 流程 1：加盟申请审批
- 「加盟管理 → 加盟申请」→ 审核 → 「通过开通」
- 自动生成门店 + 商家账号（弹窗显示账号密码）
- 通知商家下载桌面端

#### 流程 2：AI 解读付费闭环（v1.1 新）
```
门店提交工单（9.9 元）→ 总部受理 → 总部收款 → 收款后自动生成解读
```
- 「加盟管理 → 服务工单」演示完整流程
- AI 接口配置（系统设置 → AI 接口配置）
- 7 家模型演示切换
- 结构化解读效果展示（10 字段卡片）

#### 流程 3：报告删除权限演示
- 用 SUPER_ADMIN 账号演示删除（含二次确认）
- 用 DOCTOR 账号演示无删除按钮
- 强调：删除仅管理员可见，避免误删

#### 流程 4：设备鉴权
- 设备绑定/解绑
- 强随机密钥 + HMAC 签名心跳
- 401 拦截演示

## 第二天：分组实操（每组 2 人）

### 上午 9:00-12:00 · 实操题
- 实操 1：客户建档 → 检测 → 看报告（含 AI 解读申请）
- 实操 2：报告删除 / 返回上一级 / keep-alive
- 实操 3：服务工单（AI 解读 / 调理方案 / 远程会诊 三种）
- 实操 4：账单与收款

### 下午 14:00-17:00 · 故障演练
- 故障 1：AI 解读 `{raw:"..."}` → 点"重新生成"
- 故障 2：PDF 503 → 检查 CHROMIUM_PATH
- 故障 3：门店越权访问 → 403/404
- 故障 4：断网 → 离线演示模式

### 考核（30 min）
每位员工完成：
- 5 道理论题（角色权限 / AI 流程 / 设备定位 / 错误码 / 应急）
- 1 次实操（完整跑通"门店申请 AI 解读 → 总部受理 → 收款 → 解读生成"）

## 关键话术（对加盟商/客户）

### 对加盟商
> "系统用 50 类循证数据（PubMed 论文 + 国家指南）做参考，AI 解读是 MiniMax M3 模型生成的中医体质分析，最终由您的医师把关。报告里的'评估依据'标签页可以直接点链接看参考文献来源。"

### 对客户
> "您的报告有评分、指标、结论、AI 解读，**居家调理建议**是给您回家参考的，纯文字无虚假数值。如果想让我帮您看具体某项，点'服务申请 → 远程会诊'，¥99 总部专家出意见。"

### 应对"设备质疑"
> "检测仪是硬件加密狗 + 真实算法生成的报告，**不是拍脑袋的**。我们背后有 50 类循证依据 + 中医体质算法 + 风险分级。"
