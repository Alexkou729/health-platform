# 生物电设备采购清单 + 接入方案（真实检测硬件）

---

## 一、结论（诚实定位）

1. **手掌生物电阻抗（BIA）和皮电（GSR/EDA）是真实、有科学依据的检测方法**，可用于健康评估：
   - **BIA（生物电阻抗分析）**：通过弱电流测人体阻抗，估体脂率、肌肉量、水分、基础代谢。验证对照 DXA/水下称重，正确操作时一致性高。（PubMed 23299872 等）
   - **GSR/EDA（皮肤电/皮电反应）**：测皮肤电导变化，直接反映交感神经（自主神经系统）活动，用于压力/应激/放松度评估。（IEEE 9441808；KCL EDA 研究）
   - **良导络（Ryodoraku，中谷义雄 1950）**：在经络反应点测皮肤电阻/电导，对应自主神经兴奋性，是「经络电测量」的正统方法。（日本良导络学会期刊）
2. **PB-66（VID 0x5608 / PID 0x080D）不是这类传感器**：它是飞天诚信 Rockey 加密狗（USB Tender Key），USB 描述符里没有 ADC/电极，只做质询-应答认证，**测不了阻抗或皮电**。「量子弱磁场共振 522 项」是营销话术（315 已曝光：用公猫测出卵巢护理建议）。
3. **换用真传感器后，系统能诚实输出**：实测项（心率/HRV/皮电/体成分）+ 评估项（器官风险，基于人口学与实测+文献共识），并附科学依据。

## 二、可采购的开源/无加密狗硬件（三档）

### 首选（覆盖最全、最好接入）：BITalino (r)evolution
- **价格**：板卡套件 €149–250 起；EDA 传感器 €59.9；ECG 传感器另购
- **测什么**：真·皮电 EDA/GSR、心电 ECG、肌电 EMG、脑电 EEG、加速度、光感
- **为什么**：PLUX 开源，官方 Python API（`pip install bitalino`）+ Node/Java，蓝牙 BLE + USB，即插即用
- **对应报告模块**：自主神经/压力/疲劳/睡眠（EDA）+ 心脑血管（ECG）
- **购买**：官方 https://bitalino.com ；国内代理 http://plux.gofitness.com.cn/products?product_id=12 ；EDA 传感器 https://www.mindtecstore.com/BITalino-sensor-for-electrodermal-activity-EDA-assembled

### 性价比/最快跑通：Seeed Grove GSR + Arduino UNO R3
- **价格**：Grove GSR 传感器 ~$13.77–15（DigiKey 现货 599 片）；Arduino UNO ~$20（总计约 ¥100–150）
- **测什么**：真·皮肤电导 GSR（两指电极）
- **为什么**：串口直读，Electron 用 `node-serialport` 一天可跑通
- **对应报告模块**：经络/自主神经评估（良导络电导）
- **购买**：DigiKey https://www.digikey.hk/zh/products/detail/seeed-technology-co-ltd/101020052/5488086 ；Wiki https://wiki.seeedstudio.com/cn/Grove-GSR_Sensor/

### 研究级（ECG+PPG+血氧）：HealthyPi 5（ProtoCentral）
- **价格**：HPI5-BASIC ~$299（ECG 电极+SpO2+体温）；HPI5-COMPLETE ~$425（含屏幕/外壳/电池）；Mouser 中国 ¥2473–3515
- **测什么**：3 导联 ECG、PPG、SpO2、呼吸、体温，可扩展 GSR
- **为什么**：开源（GitHub 有固件+SDK），WiFi/BLE，研究级精度
- **对应报告模块**：心脑血管、体成分辅助、睡眠
- **购买**：Mouser https://www.mouser.cn/c/?m=ProtoCentral ；GitHub https://github.com/Protocentral/Healthypi5

### 真·体成分 BIA（进阶）：ADI AD5940 EVAL-AD5940BIOZ
- **价格**：~$500–720 / ¥2362–3469
- **测什么**：真·生物电阻抗（阻抗幅值/相位），可做 BIA（体脂/肌肉/水分）与 EDA
- **为什么**：ADI 官方评估板，最「真」的 BIA 前端
- **对应报告模块**：体成分/肥胖/基础代谢
- **购买**：DigiKey https://www.digikey.cn/zh/products/detail/analog-devices-inc/EVAL-AD5940BIOZ/10124784
