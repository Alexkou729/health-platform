# 智能健康风险评估仪 · ODM 委托生产需求规格书

> 文档版本：V1.0 ｜ 编制日期：2026-08-25
> 用途：交付代工厂，作为产品定义、硬件、通信协议、检测策略、报告逻辑的唯一依据。
> 配套物料：`报告参数对照表.md`（522 项指标）、`报告参数对照表.json`（结构化数据）

---

## 一、产品定义

| 项目 | 说明 |
|---|---|
| 产品名称 | 智能健康风险评估仪（品牌名待定，支持贴牌 OEM） |
| 产品形态 | 手持式手掌接触传感器 + USB 连接电脑/平板 |
| 核心流程 | 手掌接触 → 60 秒检测 → 生成 47+ 类健康评估报告 |
| 目标用户 | 养生馆、医馆、美容院、健康管理机构（连锁加盟场景） |
| 系统形态 | 配套我方自研 SaaS 平台（桌面端 + 小程序 + 云端），设备仅作为数据采集终端 |

## 二、硬件规格要求

| 项目 | 规格 |
|---|---|
| 传感器 | 手掌接触式导电电极片（左右手各一组或多点接触） |
| 接口 | USB 2.0（Type-A 或 Type-C，优先 HID 免驱） |
| 指示灯 | 三色 LED：待机绿色常亮 / 检测中蓝色闪烁 / 完成绿色亮起 |
| 供电 | USB 5V，≤100mA |
| 外壳 | 我方品牌贴牌，支持丝印 Logo、定制配色（健康绿主题） |
| 尺寸重量 | 手持式，建议 ≤150g，便于门店操作 |
| 线材 | USB 线 ≥1.2m，抗干扰屏蔽线 |

## 三、通信协议要求（★ 核心条款，不可妥协）

**代工厂必须开放完整通信协议或提供 SDK（Windows/macOS），否则不具备合作条件。**

需明确交付以下内容：

1. **设备枚举**：VID/PID、设备描述符、唯一序列号读取方式（支持一机一码，用于我方设备授权管理）。
2. **开始检测命令**：触发 60 秒采样的 HID 输出报告字节序列。
3. **数据帧格式**：采样数据的帧结构（帧头、序号、时间戳、数据位、校验位），以及数据明文格式或解密算法/密钥。
4. **结束检测命令**：停止采样并返回最终数据的命令。
5. **LED 控制命令**：待机/工作闪烁/完成 三种状态的指示灯控制字节。
6. **异常处理**：设备拔出、超时、校验失败的返回码定义。

> 我方要求：**数据必须可解析（明文或提供解密 SDK），不得做成封闭加密狗**。这是与现有旧设备（PB-66 加密狗不可读）的根本区别，也是本项目立项的前提。

## 四、检测策略

| 项目 | 策略 |
|---|---|
| 检测时长 | 60 秒（可配置 30~120 秒） |
| 采样频率 | ≥1 次/秒（建议 10~60Hz） |
| 数据预处理 | 去噪、去漂移、异常帧剔除 |
| 输出 | 一组结构化生理指标值（对应下方 522 项指标中的适用项） |

## 五、报告生成逻辑

设备仅输出原始指标值，**报告由我方 SaaS 平台生成**（分级判断、话术、AI 解读、PDF 导出均在软件侧完成）。

1. **指标库**：共 50 类报告、522 项检测指标，每项含「检测项目名 + 正常范围 + 异常分级」，详见 `报告参数对照表.md`。
2. **异常分级规则**：
   - 正常 `-`：实测值在正常范围内
   - 轻度异常 `+`：偏离正常范围 <10%
   - 中度异常 `++`：偏离 10%~20%
   - 重度异常 `+++`：偏离 >20%
   - 酸碱度专项：pH 偏离 7.35-7.45 判为酸性/碱性
3. **报告分类**：心脑血管、胃肠、肝胆、肾、肺、脑神经、内分泌、免疫、微量元素、维生素、氨基酸、骨密度、经络、皮肤、妇科、前列腺、男性性功能、基本体质等 47 类 + 综合报告 + 专家分析 + 手工分析。

## 六、OEM 要求

| 项目 | 要求 |
|---|---|
| 贴牌 | 外壳 Logo、开机画面、包装彩盒均我方品牌 |
| 软件 | 不采购原厂软件，仅采购硬件 + 协议/SDK；配套软件由我方平台承担 |
| 数量 | 首批试单（建议 10~50 台），后续连锁加盟放量 |
| 认证 | 提供产品质检报告、CE/FCC（如出口）、医疗器械属性说明（按实际申报类别） |
| 交期 | 打样 ≤30 天，量产 ≤45 天 |

## 七、验收标准

1. 设备插入电脑后，我方 SDK 可枚举并读取唯一序列号。
2. 发送「开始检测」命令后，60 秒内持续返回符合协议的数据帧，蓝灯闪烁。
3. 发送「结束检测」后返回完整数据，我方可解析出结构化指标值。
4. 数据与同型号设备复测一致（重复性验证）。
5. 三色 LED 状态切换正确。
6. 连续运行 24 小时无掉线、无异常。
